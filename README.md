# Church Management System

A web and mobile Church Management System developed for **The International United Apostolic Faith Church**.

The system is designed to make church administration easier by bringing important church information, activities and communication into one organised platform.

## About the Project

The church currently manages information using different methods such as paper records, spreadsheets, WhatsApp groups, telephone calls and verbal communication.

As the church grows, managing information through these separate methods can become difficult. Information may be harder to find, update or communicate, while activities such as attendance, events and donations require additional administrative work.

The Church Management System provides a centralised solution for managing these activities through a website and mobile application.

## Project Goals

The main goals of the system are to:

- Centralise church information in one system
- Reduce the use of paper records and spreadsheets
- Improve communication between church leadership and members
- Make member management easier
- Improve attendance tracking
- Simplify event management and registration
- Improve donation and financial record keeping
- Provide useful reports
- Provide different access levels for different users
- Give members access through both web and mobile platforms
- Provide a simple and easy-to-use interface
- Protect important church and financial information
